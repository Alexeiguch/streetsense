# Candidate datasets and videos for the signal classifier and the detector/reader

Researched 29 Oct 2026. Every link below loaded (HTTP 200) on that date unless it is marked otherwise. Nothing was downloaded. Sizes and licences come from the source page, the GitHub licence API, or the Kaggle, HF or Mendeley metadata. "Unknown" means I could not confirm the value. Datasets we already use (the PTL/ImVisible dataset, Wikimedia "Pedestrian signals by country", and our dev clips) and the ones already rejected (Bosch BSTLD, DTLD, Ampel-Pilot, Mendeley 809-image set, Roboflow) are covered in `eval/SOURCES.md` and not repeated here.

Classes we need: walk / stop / countdown / other (64 px crops). Fit: **train**, **test**, or **both**. Priority: 1 = add next, 3 = only if needed.

## Recommendations: top 3 to add next

1. **PTLD (Brazil)**: per-light **boxes** with go/stop/off. Boxes give clean 64 px crops without our YOLO pass. The "off" class directly feeds `other`/flashing, and the Brazilian head shapes broaden coverage. Blocker: confirm the licence with the authors (PUCRS). Until then, use it for internal test only.
2. **PTL-Crosswalk (Brazil/France)**: the only pedestrian set with many **night (687) and rain (748)** frames, which is our weakest area (READER.md: night crops are a small share). Labels are per image, so label crops the same way we did for PTL. The licence is unknown, so ask ronaldosm.
3. **Wikimedia "Videos of traffic signals" tree**: CC-licensed and attributable, so it is safe now. Use it to build more **held-out test clips** for countdown, flashing and blinking-red, plus the Düsseldorf green/red man. Follow the existing SOURCES.md process.

Next: a **Mapillary API pull** (CC BY-SA) filtered to `traffic-light--pedestrians` in London/Manchester and Montevideo, to fill the regional gaps below.

## Gaps
- **UK** (puffin/pelican/toucan, near-side heads, flashing green man at pelicans): no dataset. Use Mapillary plus Commons "Category:Puffin_crossings" (exists) and record our own clips.
- **Uruguay / Southern Cone**: no dataset found. PTLD (Brazil) is the closest. Use Mapillary for Montevideo.
- **Flashing / blinking states**: still images can't show a flash. We need video (Commons, our own recordings).
- **US white walking-person and orange hand at night**: still a small share. LISA is non-commercial, so record our own or use Commons/Pexels clips.
- **Egocentric walking at crossings with signal labels**: none open. FPVCrosswalk only labels crosswalks.
